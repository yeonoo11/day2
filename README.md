## 🍊 4. 제주 특산물 도감 📚

### 🍊 감귤 (귤)
- 🌟 제주도 하면 가장 먼저 떠오르는 대표 특산물이에요
- 🧡 새콤달콤해서 남녀노소 모두 좋아해요
- 🍂 보통 늦가을부터 겨울까지 맛있는 시기예요
- 📦 선물용 박스로도 인기 만점이에요

### 🍋 한라봉
- 🏔️ 한라산을 닮은 볼록한 꼭지가 매력 포인트예요
- 💛 향이 진하고 과즙이 많아요
- 😋 껍질이 두꺼워서 까먹는 재미가 있어요

### 🍊 천혜향
- 🌸 하늘이 내린 향기라는 뜻의 이름이에요
- 🍯 달콤함이 진해서 디저트처럼 먹어요

### 🐖 흑돼지
- 🔥 불에 구워 먹는 제주 대표 음식이에요
- 😍 고소하고 쫄깃한 맛이 일품이에요
- 🥬 쌈 싸 먹으면 더 맛있어요

### 🐟 갈치와 옥돔
- 🌊 제주 바다에서 만나는 싱싱한 생선이에요
- 🍲 갈치조림, 옥돔구이로 인기가 많아요
- ✨ 은빛 갈치는 보기만 해도 반짝반짝해요

### 🍡 오메기떡
- 🟣 쫀득쫀득한 제주식 전통 떡이에요
- 🫘 팥고물이 올라가 달콤해요
- ☕ 차와 함께 먹으면 꿀맛이에요

### 🐴 말(조랑말)
- 🌿 제주 들판에서 자유롭게 풀을 뜯는 모습이 귀여워요
- 🏇 승마 체험도 할 수 있어요

### 🌿 한라산 청정 먹거리
- 🍵 녹차, 고사리, 버섯 같은 산 먹거리도 있어요
- 🌱 맑은 공기를 먹고 자란 재료들이에요

## ❓ 5. 질문 예시 자세히 보기 🔎

### 🍊 질문 1: 귤이 일년에 몇개 출하 가능한가?
- 🎯 **목적**: 귤의 연간 출하 규모를 알고 싶어요
- 🔍 **에이전트가 할 일**: 출하량 통계 자료를 찾기
- 📌 **주의**: 개수(🔢)와 무게(⚖️) 단위가 다를 수 있으니 꼭 확인해요!
- 💡 **팁**: 자료마다 기준 연도가 다를 수 있어요 📅

### 🏫 질문 2: 제주대학교는 거리가 제주시청에 얼마나 되나?
- 🎯 **목적**: 두 장소 사이의 거리를 알고 싶어요
- 🔍 **에이전트가 할 일**: 지도 정보를 바탕으로 거리 계산하기
- 🚗 자동차로 갈 때와 🚌 버스로 갈 때가 다를 수 있어요
- 💡 **팁**: 직선거리인지 도로 거리인지 함께 알려주면 좋아요

### 🎁 질문 3: 다른 특산물이 있는가?
- 🎯 **목적**: 귤 말고도 어떤 특산물이 있는지 알고 싶어요
- 🔍 **에이전트가 할 일**: 제주 특산물 목록을 정리해서 보여주기
- 😊 위의 도감(🍊🍋🐖🐟🍡)을 참고해요
